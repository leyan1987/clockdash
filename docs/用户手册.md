# 时钟看板 · 用户手册

这份手册写给**使用时钟看板的普通用户**，不涉及代码与服务器部署。
把一台旧平板（或任意安卓平板/手机/电视盒）变成一块常亮的看板：大字时钟、农历月历（含节假日调休）、一周天气、循环待办与到点全屏提醒。

---

## 一、先弄清楚：你用的是哪个版本

时钟看板分两种版本，**看平板设置页里的"服务器地址"**：

- **填了服务器地址**（形如 `http://xxx.xxx:8765`）→ 你用的是 **在线版**
- **留空** → 你用的是 **单机版**

两种版本日常界面完全一样，区别在于**数据存在哪、怎么改、能几台设备一起用**。先看总表，后面各有一份一步步的操作说明。

### 快速对比

| | 单机版 | 在线版 |
|---|---|---|
| **需要额外买东西吗** | 不需要，装上就能用 | 需要向服务商购买订阅账号 |
| **待办/设置存在哪** | 平板自己肚子里 | 服务商的服务器上 |
| **换平板/重置后** | 数据要重新录入 | 重新登录账号，内容自动回来 |
| **改待办的方式** | 平板上直接改，或手机扫码连平板改 | 电脑/手机浏览器打开网页后台改，平板约 5 分钟内自动更新 |
| **多台设备** | 每台各自独立，互不相干 | 一个账号装任意多台，**全部自动显示同一套内容** |
| **天气** | 平板自己联网取（要自己申请高德 Key，免费） | 服务器统一取，开箱即用 |
| **失联告警** | 无（离线了没人知道） | 平板断网/关机超过 15 分钟，服务商可收到告警 |
| **续费** | 不涉及 | 按月/年付费，到期停同步（时钟照常显示） |
| **软件升级** | 手动：从购买渠道取新安装包覆盖安装 | 自动：通知栏提示一键安装 |
| **数据备份** | 建议自己用"导出配置"存一份 | 服务商自动备份，用户不用操心 |
| **断网时** | 时钟日历照常，天气停更 | 时钟日历照常，显示"离线模式"，恢复后自动追上 |
| **适合谁** | 只有一台平板、不想买服务、愿意自己折腾一次配置 | 想多台设备同步、想用电脑网页改内容、要省心 |

## 二、单机版操作手册

### 1. 安装应用

1. 向服务商/开发者拿到安装包，**老平板（2011-2016 年，安卓 4.0-4.4）用 `ClockDash-legacy.apk`，较新的设备（安卓 5.0 及以上）用 `ClockDash-modern.apk`**。装错版本会提示"无法安装"，换另一个即可。
2. 平板：设置 → 安全 → 勾选"**未知来源**"（允许安装非应用商店程序）。
3. 把 APK 拷进平板（数据线/存储卡/微信文件传输均可），用文件管理器点击安装。
4. 装好后桌面会出现**时钟看板**图标（部分老桌面找不到图标时，去"设置 → 应用"里打开，或换一个桌面启动器）。

### 2. 进入设置页

看板界面特意把入口藏起来了（免得日常误触）：

> **右上角连点 3 次** / **长按时钟** / 按平板的**菜单键** —— 三种方式任选其一。

### 3. 首次配置（单机版）

在设置页：

1. **服务器地址：留空**（这就是单机版的标志）。
2. **填写天气配置**（不填天气也能用，只是天气一栏没有数据）：
   - **高德 Key**：自己申请一个免费的（方法见下一节）
   - **行政区码**：6 位数字，是你所在区县的行政区划代码（可以在"国家统计局县及县以上行政区划代码"网页查询，例如临沂市兰山区是 `371302`）
3. 点「保存并测试连接」。看到天气栏出现温度即成功。

**申请免费高德 Key 的步骤**：

1. 电脑浏览器打开 `https://lbs.amap.com`，注册/登录高德开放平台（个人账号即可）。
2. 进入"控制台 → 应用管理 → 创建新应用"，应用名随便填（如"时钟看板"）。
3. 在应用下"添加 Key"，**服务平台务必选"Web 服务"**，提交后得到一串 Key（字母数字）。
4. 把这串 Key 填进平板设置页。免费额度每天有几千次，看板用量远低于上限，个人使用完全够。

### 4. 录入待办（两种方式）

**方式 A：直接在平板上编辑**

1. 设置页 →「**管理本机待办**」。
2. 点「＋ 添加一条」或点已有条目修改、长按删除。
3. 每条待办可设置：标题、日期、时间、**重复**（不重复/每小时/每天/每周/每月/每年）、提前提醒分钟数、间隔、星期、结束日期。
4. 改完点「保存」，提醒闹钟自动重排，回到看板即可看到。

**方式 B：手机扫码编辑（打字方便，推荐）**

1. 平板设置页点「**手机扫码配置**」，平板会出现一个二维码和一个 **4 位配对码**。
2. 手机扫二维码（或浏览器输入二维码下方显示的地址），打开配置页。
3. 页面上半部分是基本设置，**下半部分是待办编辑**：增删改完成后点「保存待办到平板」。
4. 提交时需要输入平板屏幕上显示的 4 位配对码（防局域网里别人误改）。
5. 保存后平板闹钟立即重排，此页面仅在平板停留期间有效，退出即关闭，安全无害。

### 5. 日常使用

- **到点提醒**：待办时间到时平板会亮屏、响铃、弹出大按钮提醒框（「知道了」/「10分钟后再提醒」）。锁屏状态也能弹出；错过几分钟内会自动补弹。
- **提醒声音**：确认平板**媒体音量**不为 0；设置页可开关"提醒时播放铃声并震动"。
- **常亮**：平板插上充电器，系统设置里开启"**充电时屏幕永不休眠**"（设置 → 显示 → 休眠/保持唤醒）；看板自身也会尽量保持亮屏。
- **夜间模式**：设置页可设定时段（如 22:30-06:30），到点自动把亮度降到很低，可选"只显示时钟"。
- **全屏**：设置页或看板右下角可切换全屏沉浸。
- **时间不准**：平板系统设置里开启"自动确定日期和时间"（时区选北京时间）。农历、节假日、提醒全依赖系统时间。

### 6. 数据与备份（单机版）

- 所有数据（待办、设置、高德 Key）都存在**这台平板自己**的存储里。
- 建议把待办列表截图或抄一份留存；换平板时需要重新录入一遍。
- 平板恢复出厂 = 数据全部清空，请谨慎操作。

## 三、在线版操作手册

### 1. 你会拿到什么

购买后，服务商会给你三样东西：

| 内容 | 样子 | 用途 |
|---|---|---|
| **服务器地址** | `http://113.44.83.125:8765`（以实际提供为准） | 填进平板 |
| **账号口令** | `账号名:口令`（例如 `zhangsan:8f3k2m`），或只给口令 | 平板与网页后台登录 |
| **到期日期** | 如 `2026-12-31` | 到期请续费 |

> **保管好账号口令**——它同时是平板的同步凭据和网页后台的登录凭据，谁拿到谁就能改你的看板内容。

### 2. 安装与配置

1. 安装 APK（同单机版第 1 步）。
2. 进入设置页（右上角连点 3 次 / 长按时钟）。
3. **服务器地址**：填服务商给的地址（一字不差，包括 `http://` 和端口）。
4. **口令**：填 `账号名:口令`（推荐，最明确）；只填口令也可以。
5. 点「保存并测试连接」。等一两分钟，看板出现你账号里的待办与天气即成功。
6. 也可以用手机扫码方式配置（同单机版，只是把服务器地址和口令填进上半部分）。

### 3. 验证同步成功

- 看板中栏月历出现待办圆点、右栏出现"近期待办"列表；
- 状态栏会显示上次同步时间；
- 在网页后台改一条待办保存，**最迟约 5 分钟**内平板自动更新（无修改时每小时做一次完整同步）。

### 4. 日常改待办（推荐用网页后台）

1. 电脑或手机浏览器打开服务商给的**网页后台地址**（就是服务器地址，如 `http://113.44.83.125:8765/`）。
2. 用**账号名 + 口令**登录（不带冒号的那种分开学）。
3. 你只能看到**自己账号**的待办、显示设置与历史记录——别人的数据互相隔离，账号管理/备份等管理员功能也看不到。
4. 编辑待办与显示设置（夜间模式、城市、刷新频率等）→ 保存 → 平板最迟约 5 分钟自动跟上。

**网页后台能做的事**：

- 增删改待办（支持全部循环规则）
- 搜索城市自动填经纬度、推送显示设置
- 查询**历史待办**（过去发生过什么、删掉过什么，可按时间/关键词查）
- 查看设备在线状态、给平板留言

### 5. 多台设备

家里客厅、卧室、父母家各一台平板？**都填同一个服务器地址 + 同一个账号口令**即可——所有设备自动显示同一套待办与设置，改一处全部更新。想让不同房间显示不同内容，向服务商再开一个账号。

### 6. 浏览器看板（免费的"第二块屏"）

任何电脑/电视盒子浏览器打开 `http://服务器地址:8765/board.html`，输入同一个 `账号名:口令`，浏览器就变成一块与平板同步的看板（支持全屏、添加到主屏幕像 App 一样用）。适合把旧电脑显示器、带浏览器的智能电视利用起来。

### 7. 到期与续费

- **到期前**：一切正常。
- **到期后**：平板停止与服务器同步，看板顶部会出现"**订阅已到期 · 已停止同步，请续费后重连**"提示。**时钟、农历、月历、已缓存的待办提醒照常工作**，不会黑屏。
- **续费后**：什么都不用重配，平板下次同步自动恢复，提示消失。
- 到期日期以服务商后台显示为准，联系服务商续费即可。

### 8. 软件自动升级（在线版专属）

服务发布新版本后，你**不需要做任何事**：

1. 平板在平时联网时会自动发现新版本，并在后台悄悄下载（安装包只有约 300KB）。
2. 下载完成后通知栏会弹出"**看板新版本已就绪，点此安装**"。
3. 点一下通知 → 系统弹出安装页 → 点"安装"即可，内容自动恢复，无需重新配置。
   - Android 8 及以上的设备，第一次会先跳到"允许安装未知应用"开关，打开后回来再点一次即可（只需授权一次）。
4. 也可以在平板设置页点"**检查更新**"手动触发；安装期间请保持平板通电，安装完成后看板自动回来。

> 单机版没有在线升级，新版本请从购买渠道获取安装包覆盖安装（数据不会丢）。

### 8. 断网/服务器维护时

平板端有完善的离线兜底：时钟、日期、农历月历、节假日标记、夜间模式、常亮全部照常；待办提醒使用最后一次缓存的数据照常响；只有天气与"新修改的内容同步"暂停，恢复联网后最迟约 5 分钟自动追上。

## 四、单机版与在线版的详细区别

| 维度 | 单机版 | 在线版 |
|---|---|---|
| **购买** | 一次买断 APK | 按月/年订阅账号 |
| **数据存储位置** | 平板本地存储 | 服务商服务器（平板留缓存副本） |
| **数据归属与隐私** | 完全在你自己平板里，不经任何第三方 | 待办内容经服务商服务器中转，服务商理论上可接触（自建服务器则归自己） |
| **修改待办** | 平板直接改 / 手机扫码改，**保存立即生效** | 网页后台改 / 平板改，保存后**约 5 分钟内**同步到所有设备 |
| **生效速度** | 秒级 | 最迟 5 分钟（有修改时服务端立即推送） |
| **多设备** | ❌ 每台独立录入 | ✅ 一个账号任意多台，同一套内容 |
| **换设备/重装** | 数据丢失，需重新录入 | 重装 App 登录原账号，内容自动回来 |
| **天气数据源** | 平板直连：自己的高德 Key（HTTP 端点）或 Open-Meteo，需配置 | 服务器代理高德 + Open-Meteo 补齐，开箱即用，无需用户申请 Key |
| **一周天气补齐** | 同样 7 天（平板自己合并两个数据源） | 7 天（服务器/浏览器自动合并） |
| **节假日/调休** | ✅ 离线算法 + 联网更新数据 | ✅ 同左 |
| **农历** | ✅ 离线算法，不依赖网络 | ✅ 同左 |
| **失联告警** | ❌ | ✅ 平板离线超 15 分钟推送告警给服务商 |
| **服务商留言** | ❌ | ✅ 后台留言，平板下次轮询弹出 |
| **续费控制** | 不涉及 | 到期停同步，续费自动恢复 |
| **软件升级（OTA）** | ❌ 手动覆盖安装 | ✅ 通知栏一键安装，无需重配 |
| **备份** | 用户自行留存 | 服务商自动每日备份 + 一键恢复 |
| **网络要求** | 天气需要网；纯时钟日历可完全离线 | 需要能访问服务器；断网有完整离线兜底 |
| **配置复杂度** | 中（要自己申请高德 Key + 查行政区码） | 低（填两行东西就完事） |
| **月成本** | 0 | 订阅费（含服务器与维护） |
| **适合人群** | 动手能力强、只要一台、不想持续付费 | 想多屏同步、要省心、给长辈远程维护 |

**怎么选**：

- 只有一台平板、预算敏感、愿意折腾一次配置 → **单机版**
- 有两台及以上设备、或想让异地的父母平板"永远有人管" → **在线版**（这是它最大的价值：你在自己家改一条"吃药提醒"，千里之外父母平板 5 分钟后自动出现）

## 五、常见问题

- **桌面上没有图标**：部分老桌面启动器显示不出图标。去"设置 → 应用"里打开，或按"菜单键"从最近应用进入；也可以换一个桌面启动器。
- **提醒到点没响**：① 检查设置页"提醒时播放铃声并震动"是否开启；② 媒体音量调大；③ 系统时间是否准确（开自动对时）；④ 电池优化类软件是否杀掉了本应用（把时钟看板加入白名单/信任列表）。
- **天气一直显示"等待数据"**：单机版请确认高德 Key 已填、行政区码正确（6 位数字）；在线版请联系服务商检查服务器。另外天气依赖经纬度/行政区码，全空着不会有天气。
- **进不了设置**：右上角连点 3 次、长按时钟、菜单键，三种方式任选。触摸屏局部失灵时多试几个位置。
- **屏幕夜里太亮**：设置页开夜间模式，可勾"只显示时钟"。
- **屏幕不常亮**：插着充电器 + 系统设置里把"休眠"调成"充电时永不休眠"。
- **老平板电池鼓包了**：老锂电池常年插电大概率鼓包，建议**拆掉电池直接用电源适配器供电**（多数老平板支持无电池开机），安全第一。
- **订阅到期了**：时钟照常、提醒照常，只是不再同步新内容；联系服务商续费后自动恢复。
- **想换城市天气**：网页后台（在线版）搜索城市保存推送即可；单机版改行政区码或经纬度。

## 六、联系支持

- 在线版：联系你的服务商（购买渠道），提供账号名与现象描述。
- 单机版：按购买渠道联系开发者。
- 反馈问题时请附上：设备型号、安卓版本、看板版本号（设置页可见）、现象截图。
