# ClockDash 视频分镜脚本 B｜硬核技术版（约 98 秒）

**《我用 AI 写了个 264KB 的安卓 App》**
定位：面向程序员/极客圈层，靠数字、架构决策和测试全绿建立"狠活"信誉，情感只作收尾点缀。

---

## 一、给制作 AI 的总说明（整段复制即可）

- 成片：约 98 秒，竖屏 9:16，1080×1920，30fps
- 视觉基调：深色极客风。底色近黑（#0D1117 类 GitHub 深色调），点缀琥珀色 #FFB300 与终端绿 #3FB950；所有数据用等宽字体呈现
- 字幕：全程大字花字，字号 ≥ 屏宽 1/12；数字类字幕必须最大化（如"264KB"占半屏）
- 字幕双层：底部常驻口播字幕 + 大字花字（小红书大量用户静音刷视频）；每个"狠活"镜头右下角加一行灰色小字"人话翻译"，照顾非技术受众
- 口播：沉稳利落的技术区人声，约 4.5 字/秒，每条口播字数已按镜头时长配平，直接送 TTS
- BGM：节奏感电子乐/Lo-fi 鼓点，90–100 BPM，全程保持律动；每个"狠活"镜头给一次重音
- 素材分工（重要）：标【录屏·必拍】的镜头是真实终端/真机界面，**不能用 AI 生成替代**；标【AI 生成】的镜头已附中文提示词
- 数据一致性（重要）：264KB、16 个 Java 类、66 项测试（40+26）、1900–2049、minSdk 15 / targetSdk 31——全片只能用这些数字，不得改写

- **副字幕**（人话翻译）：说白了——老设备连不上新服务，让电脑当中转站
