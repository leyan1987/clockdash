在线看护 平板长时间不通讯时，服务器主动告警

平板每 5 分钟向服务器报一次到，超过设定时间没来即判定失联。 服务器在公网、平板在内网，无法反向连接平板，所以告警推送到你配置的机器人； 发给平板的留言则在它下一次轮询时带回（离线消息补发）。
流量说明：设备关机 / 离线时服务器不会向设备发任何数据（没有重试机制）， 看门狗只读写本机文件、不联网；唯一的外发是告警 Webhook，默认未配置即 0 流量， 配置后也只在状态翻转时发一次。留言最多随检查下发 3 次。
钉钉/飞书若设置了自定义关键词，请把关键词设为「平板」或「ClockDash」； 加签型机器人暂不支持。自定义渠道会 POST {"title":..., "text":...} JSON。
留言保存在服务器上，平板即使此刻离线，恢复后第一次检查也会收到（保留 24 小时，最多重发 3 次）。
